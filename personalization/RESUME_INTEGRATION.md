## Privacy

The original CV PDF is **not** committed to the repository. Only structured, job-matching facts are stored in `profile.yaml`.

## Matching behavior

The ranking layer prioritizes roles where the posting title and description align with the candidate's documented skills, project evidence, preferred locations and early-career level. It also penalizes senior/staff/lead/manager roles and unrelated support/sales functions.
